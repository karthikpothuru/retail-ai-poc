Phase 8.1 POC profile updates: in local POC mode, select the synthetic customer via POST /api/v1/demo/session and retain the cookie. Send PATCH /api/v1/customers/{customerId} with the matching ID and at least one non-null givenName or familyName. Names are trimmed and must be 1 to 80 characters. Missing or null fields are skipped. A successful update returns HTTP 200 with the updated profile. This PATCH does not accept an email change.
