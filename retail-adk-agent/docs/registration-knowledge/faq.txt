Phase 8.1 POC registration FAQ: HTTP 400 means the registration payload is invalid. Supply a valid email up to 254 characters after normalization and both names, each 1 to 80 characters after trimming. HTTP 409 means the normalized email is already registered. On local demo profile and preferences routes, HTTP 403 means the demo session is missing or its customer does not match the URL. Demo routes return HTTP 404 outside the poc profile.
