Phase 8.1 POC consent and preferences: locale defaults to en, marketingOptIn defaults to false and personalizationConsent defaults to false. In local POC mode with a matching demo session, use GET /api/v1/customers/{customerId}/preferences to read preferences. PUT to the same path with all three fields to replace them. To withdraw personalization consent, set personalizationConsent to the JSON boolean false and include the desired locale and marketingOptIn values.
